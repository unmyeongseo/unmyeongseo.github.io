# 정옥순 할매 — 실제 AI 무료상담 1회 서버

현재 GitHub Pages에는 고객 질문 입력창과 독립적인 상품 안내 화면을 구현했다. 이 폴더는 실시간 AI 답변을 생성하는 **배포 준비 코드**이며, 아직 Worker 주소·비밀키·데이터베이스가 연결되지 않았다. 따라서 아직 실제 AI 답변은 제공되지 않는다.

## 서비스 구성

- 기본 만세력·타고난 성향: 무료
- 할매에게 직접 묻기: 무료 질문 **1회**
- 추가 상담: 별도 상품, 가격 미정
- 전체 사주 풀이: 별도 상품, 가격 미정
- 분야별 재물·직업·연애·가족·월별·전생 풀이: **각각 별도 상품**, 가격 미정
- 결제 버튼과 유료 권한 부여는 구현하지 않았다.

## 서버 배포

1. Cloudflare 계정에서 Workers·D1 서비스를 활성화하고, PC에서 Node.js와 Wrangler를 준비한다. `server/wrangler.example.toml`을 `server/wrangler.toml`로 복사한다.
2. `server` 폴더에서 `npx wrangler login`, `npx wrangler d1 create jeong-oksoon-consult`을 실행하고 반환된 데이터베이스 UUID를 `wrangler.toml`에 넣는다.
3. `npx wrangler d1 migrations apply jeong-oksoon-consult --remote`로 테이블을 만든다.
4. `npx wrangler secret put OPENAI_API_KEY`와 `npx wrangler secret put IP_HASH_SALT`로 **서버 측 비밀값**을 설정한다. IP_HASH_SALT에는 길고 임의적인 문자열을 사용한다. 이 키들은 저장소에 올리면 안 된다.
5. `npx wrangler deploy`로 서버를 배포한 후, 루트의 `config.js`에서 `window.OKSOON_API_ORIGIN`을 배포된 HTTPS Worker 출처로 설정하고 GitHub Pages를 다시 배포한다.
6. 실제 휴대전화로 정상 답변 1회, 새로고침 후 2회 차단, 동시 요청, 오류 시 횟수 차감 여부, 다른 기기에서의 접근을 테스트한다.

## 보안·한계

- Responses API 요청과 모델 키는 Cloudflare Worker 안에서만 처리한다. 비밀키는 GitHub Pages 코드에 넣지 않는다.
- D1이 상담당 무료 질문 1회를 차단한다. 세션 생성은 IP 기준 하루 최대 3개로 제한하지만, **익명 이용자가 기기·VPN을 바꾸어 새 무료 상담을 여는 것은 완전히 방지하지 못한다.** 실제 유료 출시 전에는 휴대전화 인증/로그인 등 사용자 신원 확인과 사용자 단위 횟수 제한을 추가해야 한다.
- 상담 서버는 브라우저에서 전달된 만세력을 신뢰하는 **MVP 구조**다. 유료 상품을 출시하기 전 서버 쪽 만세력 재계산·절기/출생 시각 검증이 필요하다.
- 상담 정보(생년월일과 질문)를 서버가 처리한다. 공개 출시 전 개인정보 처리방침·동의·자동 보유기간 제한·삭제 기능을 마련해야 한다. 현재 코드에는 만료 세션을 자동 삭제하는 작업이 없다.
- 오래 처리 중인 요청이 실패·중단되면 reserved 값이 남을 수 있어, 재시도/중복 처리 복구 절차를 추가해야 한다.
- 유료 품목 접근권은 결제 완료를 서버에서 검증하고 DB에 기록해야 한다. 화면에 버튼을 표시하거나 숨기는 것으로는 보안을 확보할 수 없다.
- 미래 특정 사건과 건강·투자 결과를 정확히 맞힌다는 주장을 하지 않는다. 캐릭터의 대사 속 명리학 풀이와 이용자의 직접 진술은 구분한다.
